# Generative_AI_Research_50121638

This project is for REIT6811 Applied Class 6. Our research topic is
"Using Generative AI Tools – Boon or Bane".

We use this repository to organise our research files and keep track of changes.
So far, we have set up the folders and added a short description in each one.

## Folders

- Literature: Articles and other readings for our research.
- Quantitative: Survey questions, data, and analysis code.
- Qualitative: De-identified interview notes and analysis.
- Reports: Drafts, research proposals, and final reports.
- Other_Materials: Images and other supporting files.

## Finding Files

Look in the folder that matches what you need. For example, articles go in
Literature, and report drafts go in Reports.

Each folder has a README explaining what it is for. Use clear file names so
other group members can tell what a file contains without opening it.

## Working Together

- Pull the latest changes before editing files.
- Put new files in the correct folder.
- Keep original data separate from edited copies.
- Write a short commit message explaining what you changed.
- Push your changes when they are ready to share.
- Check with the group before deleting or replacing shared files.
