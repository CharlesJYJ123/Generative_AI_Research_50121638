# Generative_AI_Research_50121638

This project is for REIT6811 Applied Class 6. Our research topic is
"Using Generative AI Tools – Boon or Bane".

We use this repository to organise our research files and keep track of changes.
So far, we have set up the folders and added a README to explain what each one
is for. Research files can be added as the project develops.

## Folders

```text
Literature/
  Articles/
  Reading_Notes/
Quantitative/
  Survey_Materials/
  Raw_Data/
  Processed_Data/
  Scripts/
  Results/
Qualitative/
  Interview_Materials/
  Transcripts/
  Analysis/
Reports/
  Drafts/
  Final/
Other_Materials/
  Images/
  Information_Sheets/
```

- Literature: Readings and our notes about them.
- Quantitative: Survey questions, data, analysis code, and results.
- Qualitative: Interview materials, de-identified transcripts, and analysis.
- Reports: Drafts and final versions of proposals, papers, and reports.
- Other_Materials: Images and general project information sheets.

## Finding Files

Open the main folder that matches what you need, then choose the relevant
subfolder. For example, survey questions go in Quantitative/Survey_Materials,
and a draft report goes in Reports/Drafts. Each folder has a README explaining
what belongs there.

Use short, clear file names with underscores instead of spaces. Add a date
in YYYY-MM-DD format or a version number when it helps distinguish files.
For example: survey_questions_v01.docx or research_report_2026-09-18.docx.
These are naming examples; the files have not been added yet.

## Working Together

- Pull the latest changes before editing files.
- Put new files in the correct folder.
- Keep original data unchanged and save cleaned copies in Processed_Data.
- Write a short commit message explaining what you changed.
- Push your changes when they are ready to share.
- Check with the group before deleting or replacing shared files.

Keep completed consent forms, identifiable participant data, and private
contact details in approved secure storage outside this repository. Only
add research materials that we are allowed to share.
